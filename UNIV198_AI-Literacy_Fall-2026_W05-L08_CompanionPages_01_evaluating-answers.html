Four Questions for Any Answer

The model writes; you judge. Four questions, in this order, every time. They are also how Assignment 1 is being marked, and what the midterm (Week 11) asks.

1Correct?

Check the facts you can check: every number, date, name, quote and citation you will reuse. Two minutes per reused fact (Lecture 3). If you cannot check it, you cannot use it.

2Complete?

What did the task need that the answer left out? Smooth answers skip the hard part. Compare against the task, not against the answer's own outline.

3Appropriate?

Right reader, right length, right register, right format. An accurate answer for the wrong reader is still the wrong answer.

4Checkable?

Does it show its sources, steps or structure so that question 1 was possible? An answer that cannot be checked scores zero here, however good it sounds.

The habit: before you reuse a fact, you can say in one sentence where you checked it. If you cannot, it is not yet a fact; it is a token sequence.

Eight failure patterns worth recognising on sight

Confident hedge

“is generally considered”, “experts agree”: a claim with no owner.

Invented specifics

A precise number, year or name that makes the answer feel checked. It is not.

Scope creep

Answers a neighbouring, easier question, fluently.

Sycophancy

Agrees with the premise in your question, including the wrong ones.

Format drift

The table you asked for turns into prose by the second answer.

Smoothing

The hard part of the task is summarised away in one tidy sentence.

Apology loop

“You are right, I apologise” followed by a new guess, not a check.

Stale knowledge

True at the cut-off, not now. Ask for the date it relies on.

None of these is a bug. Each is the likeliest text for the context you gave (Lecture 3). Recognising them is faster than preventing them.

What the Room Usually Finds, and Comparing Two Tools Fairly

The fluent one loses

Answer A is longer and more confident in every pair. It scores lower on checkable every time, and usually on complete.

Complete is the split

Pairs agree on correct and appropriate within a point. Complete is where they argue, because it needs the task, not the answer.

Nobody checked the number

Both answers contain one figure. Almost no pair looks it up. That is the two minutes Assignment 1 asked for.

Comparing two tools fairly (Assignment 1, in hindsight)

Same everything

  • Same prompt, word for word, pasted; same input text
  • Run each tool twice: one run is a sample (Lecture 3)
  • Same settings you know of: search on or off in both, thinking mode on or off in both
  • Record the date, the tool name, and the prompt

Takeaways

Four questions, in order

Correct, complete, appropriate, checkable. The fourth decides whether the first was even possible.

Two minutes per reused fact

A primary source, not another chatbot. If you cannot say where you checked it, it is not yet a fact.

Patterns, not bugs

Confident hedge, invented specifics, scope creep, sycophancy, format drift, smoothing, apology loop, stale knowledge. Each is a prompt for the next follow-up.

The marker reads your checks

Not the tools' prose. An answer you could not check gets the follow-up, not the grade. The midterm gives you a task, a prompt and an answer, and asks exactly these four questions.
